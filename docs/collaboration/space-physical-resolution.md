# Mobile local physical room resolution

[Mobile implementation aed49dcb](https://github.com/fajarxfce/hris-mobile/commit/aed49dcbc1bd430533f77cab09302f5c8ee68221) transfers
one exact physical incoming hint through its owned local binding. Registration supplies the
configured provider name. No provider/transport request, room creation or new wake is involved.
Generation, FIFO position, head, source and retry survive conversion; unfinished logical work stays
separate. Source-bound logical reads now check the exact installed original and native parent.

[Validation](../measurements/collaboration-space-physical-resolution-2026-11-11.json) passed 168
focused desktop/browser cases and 11,264 full cases (9,226 fresh +2,038 exact unchanged controls).
All prior case IDs and unchanged dependency closures are verified. Android release compile/lint,
browser/Wasm, iOS metadata, architecture, formatting and detekt pass. No new native SDK execution,
Apple execution or phone delivery is claimed.

Before worker integration, Mobile must classify ordinary queue CAS contention as bounded retry,
then add source-aware physical selection/deferral and app worker tests. Published Group physical
room lookup and unpublished Company original lookup retain different coordinates and admission.
Provider inventory, key-only recovery and raw collector activation remain required. Group source,
fixtures, schema and deployment are unchanged. All 54 communications acceptance groups remain open.
